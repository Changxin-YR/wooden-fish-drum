# 静心木鱼 B 版视觉回退设计

## 背景与目标

当前提交 `5115776` 完成了 API 22、可选目标、右上落槌、八档趋势、即时文字刷新和上架相关修复，但同时改变了已获认可的界面风格。用户确认以 `docs/qa/screenshots/muyu-v2-practice-fit.jpeg` 所示 B 版作为视觉基准，恢复其深色、紧凑、沉静的界面语言，同时保持当前功能不变。

本次采用选择性视觉回退，不直接执行 `git revert 5115776`。功能与视觉混合在同一提交中，整提交回退会删除已经验收的业务能力。

## 成功标准

- 首页、统计页、设置页和底部导航恢复 B 版的层级、密度、配色、卡片边界、字体尺度与留白节奏。
- 深色主题以 B 版截图为主基准；浅色主题沿用相同结构，并使用对应的浅色 token 保证可读性。
- 当前全部业务功能、持久化数据、API 22 配置和 phone/tablet/2in1 支持保持不变。
- 不改变 `com.max.muyu`、版本号、签名、发布状态、权限集合或离线属性。
- 标准检查、Hypium、debug、ohosTest、release 和可用 API 22 设备回归通过。

## 视觉架构

### 共享主题

`ThemePalette` 继续作为唯一颜色来源，但 token 值和组件使用方式调整为 B 版视觉：深色页面背景、低对比卡片、克制的暖金强调色、细边界和更紧凑的圆角。浅色主题保持同一信息层级，不创建第二套页面结构。

页面继续通过已有安全区和窗口外观服务同步状态栏、导航栏与页面背景。不得回退沉浸式布局，也不得在单个页面重新写固定安全区 padding。

### 首页

首页恢复 B 版的紧凑纵向层级和中心练习画布。动态标题仍显示“今日{自定义标签}”，只采用 B 版标题的字号、位置和间距；未自定义时仍显示“今日功德”。

木鱼区域恢复 B 版沉静背景和旧版质感，但继续使用当前可交互的木鱼主体与独立右上木槌，保留当前落槌方向、时序、点击热区、波纹、回弹和浮字行为。不得出现旧素材自带木槌与独立木槌叠加的双槌现象。

自由、目标、自动三种模式和目标档位继续存在。108、1000、10000、自定义正整数、达标封顶和“再来一次”保留，只将控件改造成 B 版紧凑控制台样式。自动模式的启动、停止和反馈逻辑不变。

### 统计页

统计页恢复 B 版深色卡片、紧凑指标区和图表视觉。八个时间档位全部保留，仍由同一个 `statsPeriod` 状态驱动服务聚合、图表和统计摘要；默认仍为“本日”。

空状态、趋势判断和真实记录数据源不变。视觉回退不得引入静态示例数据或页面本地统计逻辑。

### 设置页

设置页恢复 B 版分组密度、标题尺度、行高、分隔线和卡片表现。现有开关最小触控容器、受控主题切换、自定义文字编辑、输入校验、保存中状态、遮罩、清除确认及合规入口全部保留。

自定义文字仍以 Preferences 持久化、AppStorage 跨页同步、页面生命周期重读为刷新路径。视觉变更不得建立第二份本地文案状态作为展示数据源。

### 底部导航与宽屏

底部导航恢复 B 版较低视觉重量，并继续使用图标、文字和非颜色选中标记共同表达当前页面。触控目标不小于 48vp。

Compact 保持 B 版手机单栏构图；Medium 和 Expanded 继续使用已有断点、限宽与双栏重排。宽屏只改变排布，不复制业务组件或状态。

## 数据流与边界

- 页面与组件只调整布局和视觉属性，继续调用现有回调和状态对象。
- `PracticeController`、统计聚合服务、Repositories、设置模型和迁移版本不做行为修改。
- `FeedbackText`、目标持久化、`statsPeriod`、窗口外观同步及练习记录接口保持现有契约。
- 如旧版 UI 代码与当前事件处理冲突，以当前事件处理为准，手工移植视觉属性，不整文件覆盖。

## 异常与兼容处理

- 自定义目标非法输入继续显示现有校验反馈，不关闭弹层或静默失败。
- 自定义文字保存失败继续保留弹层并显示错误；保存成功立即刷新设置摘要、首页标题和敲击浮字。
- 目标达成后继续阻止额外计数并显示“再来一次”。
- 自动模式点击木鱼、暂停/停止以及切换工具时继续提供当前反馈，不恢复已修复的无响应行为。
- 若 B 版视觉尺寸在 320vp 或宽屏产生冲突，优先保持触控尺寸和内容完整，再通过断点调整间距，不缩小交互控件。

## 验证方案

### 自动验证

- 先为任何新增的纯视觉计算或断点映射补充失败测试；不为无逻辑的颜色替换制造脆弱快照测试。
- 执行 `scripts/check-standard.ps1`。
- 构建 debug 主 HAP、ohosTest HAP 和 release 主 HAP。
- 在可用 API 22 设备运行全部 Hypium 用例，目标保持 54/54 或更高，Failure 0、Error 0。

### 视觉与交互验证

- phone 深色首页与 B 版截图并排检查：首页层级、背景、木鱼区域、控制台和底栏。
- phone 浅色逐页检查文本对比度、卡片边界、Slider、Toggle、遮罩和系统栏色带。
- 在 320vp 检查所有设置行、模式控件和目标输入无溢出，触控目标不小于 48vp。
- 在可用 tablet/2in1 设备检查 Medium/Expanded 限宽、双栏、旋转策略和安全区；设备不可用时保留为 `blocked`，不得用 phone 结果冒充。
- 回归完整路径：自由敲击、目标切换与达成、再来一次、自动模式、文字保存即时刷新、八档趋势、主题切换、重启持久化和清除确认。
- 将本次截图和验证记录保存到 `docs/qa/`，不删除已有未跟踪 QA 中间证据。

## 非目标

- 不增加新功能、新入口、新网络能力或新权限。
- 不重写页面状态管理、控制器、统计服务或 Repository。
- 不恢复已淘汰的 V1 会话服务、用户模式或无效素材。
- 不以 B 版截图中的旧文字内容覆盖当前动态数据，也不牺牲无障碍、触控尺寸、安全区或宽屏适配来追求像素相同。
