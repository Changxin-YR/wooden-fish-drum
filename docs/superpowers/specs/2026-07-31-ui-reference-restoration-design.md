# 静心木鱼 UI 高保真还原设计

## 目标

以用户在 2026-07-31 提供的六张 phone 稿为新视觉基准，重构首页、练习记录和设置页的浅色与深色表现。主题切换必须保留当前工具、练习状态、真实统计和本地记录，只改变视觉皮肤。

“100% 还原”在本项目中指状态栏以下应用内容区的信息顺序、比例、对齐、间距、字号层级、颜色、描边、阴影和选中态均按参考稿实现。HarmonyOS 系统状态栏、系统字体栅格、实时数据数值和当前工具状态属于动态内容，不伪造成参考图中的固定值。

## 视觉基准

项目内 QA 缩略图位于 `docs/ui/reference-2026-07-31/`：

- `home-light.jpg`、`home-dark.jpg`
- `stats-light.jpg`、`stats-dark.jpg`
- `settings-light.jpg`、`settings-dark.jpg`

缩略图只用于评审，不打包进 HAP。生产页面继续使用 ArkUI 组件和现有本地素材，不把整页截图作为背景。

## 方案

采用共享结构、像素贴稿方案。浅色和深色页面共用组件树、数据和事件，只通过强类型语义令牌切换颜色、边框、阴影和背景纹理。不得为两个主题复制业务页面。

不采用以下方案：

- 深浅主题各写一套页面：会造成状态和功能分叉，维护成本接近翻倍。
- 只替换现有颜色令牌：无法修正当前字号、间距、卡片层级和控制台结构，达不到参考图还原度。

## 共享视觉系统

### 浅色主题

- 象牙暖白页面背景，白色或近白半透明卡片。
- 深棕主文字、灰棕辅助文字、浅金描边和克制暖色投影。
- 选中控件使用暖金填充、白色文字和浅金边缘。

### 深色主题

- 近黑页面背景，墨黑或深褐卡片，暗金细边。
- 米金主文字、灰金辅助文字、暖金强调和局部柔光。
- 首页、记录和设置可使用从用户稿提取的低对比远山纹理；纹理不得影响文字对比度，也不得替代组件背景。

### 共享尺寸

- phone 内容左右边距为 20vp，主标题约 30-34fp。
- 卡片圆角为 16-18vp，分段控件和命令按钮保持参考稿的胶囊比例。
- 所有可点击区域不小于 48vp。
- 字号不随视口宽度连续缩放；使用 Compact、Medium、Expanded 三档离散尺寸。
- 选中态同时使用填充或描边、字重和图标明度，不只依赖颜色，也不使用破坏稿件排版的文字前缀勾选。

## 页面结构

### 首页

phone 依次展示：品牌标题、离线胶囊、今日/累计/连续摘要、三工具分段控件、工具主体画布、计数或计时、工具控制、祝语、音频控制和固定底部导航。

- 木鱼、念珠、一炷香使用相同外层骨架，内部控制台按工具状态切换。
- 木鱼和念珠显示手动/自动、1.0/1.5/2.0 秒间隔。
- 一炷香显示 5/10/15/20/30 分钟、开始/暂停/继续和结束。
- 音频区按参考稿合并缩略图、音色说明、播放按钮、音量和振动。
- phone 优先保证主操作在单屏可达；内容超出时允许页面滚动，但底部导航不得遮挡命令区。

### 练习记录

phone 依次展示：大标题与本地说明、今日/本周/本月/全部、三项摘要、最近真实练习、本地统计和趋势。

- 摘要继续分别展示次数、练习时长和一炷香时长，不混合单位。
- 最近练习只使用真实 `PracticeSession`；无记录时显示真实空状态，不填入设计稿示例。
- 本地统计保持木鱼、念珠和会话口径。
- 趋势继续保留次数和时长两套独立纵轴；外观按参考稿压缩到同一趋势卡片。

### 设置

phone 依次展示：大标题、本地数据身份条、练习设置、音频设置、显示设置、数据与合规和固定底部导航。

- 练习设置包含默认工具和自动间隔。
- 音频设置包含敲击音、音色和音量。
- 显示设置以参考稿的深色模式开关和减少动画为主。跟随系统仍由现有主题模型兼容，但不增加参考稿之外的大型分组。
- 数据与合规只展示清除今日、清除全部、隐私说明、用户须知和版本信息。
- 参考稿未出现的“文字与触感”独立分组和开源入口不占设置主页面空间。反馈文字继续使用已保存值或默认值，旧字段和迁移别名继续保留。
- 开源许可内容并入版本信息后，删除不可达的独立路由、页面和反馈文字编辑弹层，避免保留死代码。
- 清除确认弹层继续保留遮罩、背景交互锁定和键盘避让。

## 组件边界

- `DesignTokens`：升级为浅色/深色语义色、描边、阴影、圆角和断点尺寸的唯一来源。
- `HomePage`：只编排首页区块，不承载计数、计时或持久化逻辑。
- `TodaySummaryCard`、`ToolSegmentedControl`：按参考稿重塑，但保持现有输入和事件接口。
- `WoodenFishView`、`BeadsView`、`IncenseView`：保留业务交互，调整画布尺寸、素材比例和主题光效。
- `PracticeControlDock`：承载工具控制、祝语和音频控制；不复制 `PracticeController` 状态机。
- `StatsPage`、`StatsBarChart`：重排真实统计信息和图表，不改变聚合规则。
- `SettingsPage`：按参考稿组合设置项，持久化仍通过 `Index` 回调和 `AppStore`；删除没有入口的编辑状态和回调。
- `BottomNavBar`：固定尺寸，使用背景、描边、字重和图标明度表达选中态。

## 数据与状态

`AppStore`、`PracticeController`、Repository、迁移模型和生命周期处理保持唯一业务真相源。UI 重构不得：

- 重置或伪造计数、时长、连续天数、会话或香快照。
- 在主题切换时更改所选工具或练习状态。
- 恢复已淘汰的 V1 目标模式或用户身份模式。
- 增加网络、广告、登录、支付、云同步或 WebView。

## 响应式设计

- Compact：严格以 phone 参考稿为基准，单栏排列。
- Medium：页面限宽，首页画布和控制台可双栏；记录和设置使用两列卡片但保持阅读顺序。
- Expanded：继续限宽，最多双栏，不拉伸 phone 卡片或主体素材。
- 系统字体放大时允许文本换行和区块增高，不允许文字遮挡、按钮溢出或底栏覆盖内容。

## 异常与兼容

- 空统计、空会话和未开始香计时继续显示真实状态。
- 素材无法分层时使用现有本地资源，不联网加载占位图。
- 主题、旧设置和历史数据继续走现有幂等迁移。
- 包名 `com.max.muyu`、版本、签名身份和发布状态不变。

## 验收

### 自动验证

- 先为新增的主题语义和响应式尺寸写失败测试，再实现最小生产代码。
- 运行项目标准检查、外部 HarmonyOS 标准检查、禁止能力扫描和 `git diff --check`。
- 运行全部设备 Hypium，以及 debug、ohosTest、release 构建。

### 视觉验证

- 在 API 24 phone 模拟器分别采集首页、记录、设置的浅色和深色截图。
- 对照六张参考图检查状态栏以下内容区的顺序、边距、卡片尺寸、主体比例、字号、颜色、描边、阴影、控件状态和底栏。
- 使用布局树确认触控区不小于 48vp、内容与底栏无重叠、弹层背景不可交互。
- tablet 和 2in1 需在对应模拟器或真机补充 Medium/Expanded 运行证据；没有设备时保持 `blocked`，不能用 phone 结果替代。

## 发布边界

本次工作只调整 UI 和必要的本地展示资源，不修改版本号、发布身份或签名。真实发布仍需要签名、备案、隐私政策公网 URL、素材授权以及 tablet/2in1 运行证据。
