# 静心木鱼界面优化与修复设计

## 目标与边界

在现有 HarmonyOS 6.0.2 API 22 Stage 工程上增量完成主题、安全区、设置刷新、木鱼目标、木槌动画、八档趋势和应用名称统一。保留现有三工具、真实本地统计、Preferences 持久化和 phone/tablet/2in1 响应式结构，不恢复旧 `SessionService`，不增加网络、登录、广告、支付或云能力，不修改 `com.max.muyu`、应用版本号和签名身份。

项目现有共享代码位于 `constants/`、`utils/`、`stores/`、`repositories/` 和 `services/`。不新建职责重复的 `common/`。

## 共享主题与窗口

- `ThemePalette` 是页面颜色的唯一语义入口，`DesignTokens` 只保存尺寸和不随主题变化的常量，消除两套背景色造成的接缝。
- 页面、练习画布、底栏、状态栏和导航栏均消费 `ThemePalette.page`；卡片只在需要形成信息层级时使用 `ThemePalette.card`。
- 新增共享窗口外观服务。`EntryAbility` 负责启用全屏布局、读取系统避让区和监听窗口变化；主题切换后由根页面调用同一服务更新系统栏颜色和图标明暗。
- 根页面保存顶部、底部安全区值。背景扩展到系统栏区域，主内容和底部导航使用避让值，页面不各自添加固定状态栏 padding。

## 设置与实时刷新

- `AppSettings.feedbackText` 继续作为唯一业务字段，`currentText` 仅保留迁移兼容，不作为页面数据源。
- 恢复自定义文字弹层和校验工具。保存流程为：校验去空格后的内容、写入 `AppStore`、持久化 Preferences、由 `Index.syncFromStore()` 生成新的 `AppSettings` 实例，再关闭弹层。
- 保存失败或非法输入时弹层保持打开并展示行内错误；保存成功后设置页摘要、首页浮字和顶部标题在同一次状态刷新中更新，冷启动由 `SettingsRepository` 恢复。
- 所有 Switch 行使用可收缩文本区和独立最小触控区；Toggle 本体不缩小，外层不得裁切，在 320vp 下仍保留完整开关。

## 木鱼目标与动画

- 在 `AppSettings` 增加持久化目标值，默认 108；预设为 108、1000、10000，自定义仅接受正整数并设置合理存储上限。
- 木鱼练习模式保留手动和自动，并增加目标入口。目标模式使用当前练习计数计算本轮进度，不改变今日累计统计。
- 达标时 `PracticeController` 标记本轮完成并停止自动节律；额外敲击不增加本轮与统计。界面显示完成状态和“再来一次”，点击后只重置本轮状态。
- 不恢复旧会话状态机。目标判断、停止和重置都属于现有 `PracticeController`。
- 木鱼主体使用去除背景和静态木槌的派生透明资源；木槌由 ArkUI 独立绘制，静态锚点位于右上方，保持现有 90ms 落槌与 180ms 回弹手感，从右上朝木鱼表面旋转/平移且不越出画布。
- 顶部统计标题由共享文字工具生成：去除末尾 `+数字` 或 `＋数字`，空标签回退“功德”，结果为“今日{标签}”。

## 八档趋势

- `StatsPeriod` 扩展为本日、本周、本月、本年、近七日、近四周、近三月、近一年。
- 默认档位为本日，选中值通过 AppStorage 在一级页面之间共享；重新启动仍回到本日。
- `StatsPeriodService` 是范围、分桶、汇总、会话过滤和纵轴最大值的唯一计算入口。
- 本日为今日单桶；本周为本周一至今日逐日；本月为月初至今日逐日；本年为一月至当前月逐月；近七日为今日向前七日逐日；近四周为包含当前周的四个自然周；近三月为包含当前月的三个月；近一年为包含当前月的十二个月。
- 页面使用两行选择器展示两组档位，图表和摘要始终消费同一个 `StatsPeriodView`。

## 应用名称与合规

- 资源字符串中的模块说明、Ability 说明和 Ability label 统一为“静心木鱼”，`module.json5` 继续引用资源，不修改 bundleName。
- 保持 phone、tablet、2in1 声明与现有响应式断点；保持仅振动权限，无网络权限。
- 竖屏为主要 phone 布局；tablet/2in1 继续支持窗口宽度重排，不添加与现有多设备声明冲突的强制横竖屏限制。

- 先为文字标签解析、目标校验/持久化/完成重置、八档时间范围与主题 token 写失败 Hypium 测试，再写最小实现。
- 执行标准检查、debug/ohosTest/release 构建和 API 22 phone Hypium。
- API 22 模拟器验证 320vp 级最小宽度下 Switch、目标弹层、自定义文字即时刷新、冷启动持久化、目标完成/再来一次、八档趋势切换和系统栏色带。
- 深浅主题分别归档首页、趋势页、设置页截图到 `docs/qa/screenshots/`；tablet/2in1 无对应设备时继续明确标记运行态验证为 `blocked`。
