# 木锤位置调整设计

## 目标

将首页木锤的静止位置上移到用户标注区域，使木锤自然悬停在木鱼上方，同时保持现有木鱼、标题和页面整体布局不变。

## 已确认方案

- 采用视觉对比中的 B 方案。
- 木锤横向基准保持 `x: '53%'`。
- 木锤纵向基准由当前值调整为 `y: 45`。
- 木锤静止角度由 `-12` 度调整为 `-4` 度。
- 击打动画完成后必须恢复到新的 `-4` 度静止角度，避免首次点击后位置回退。

## 实现范围

仅修改 `entry/src/main/ets/components/WoodenFishView.ets` 中木锤的静止位置、初始角度和动画结束复位角度。现有动画时长、缩放、透明度、横向位置及击打位移先保持不变。

本次不调整木鱼图片位置、页面标题、计数区域、响应式断点或其他页面组件。若真机验证发现新的木锤基准导致击打动画明显无法落到木鱼上，只对击打阶段的必要位移或角度做最小修正，并以不改变动画节奏为约束。

## 状态与行为

组件首次显示时，木锤位于 B 方案对应的上方位置并保持 `-4` 度。用户点击木鱼后，木锤继续执行现有击打动画；动画结束后回到相同的 B 方案静止位置和角度。重复点击不得产生累计偏移。

## 验证标准

- 静止状态截图中，木锤位置与已确认的 B 方案一致，位于木鱼上方，不遮挡标题，也不与木鱼产生不合理重叠。
- 点击木鱼时，木锤动画仍能形成明确的击打动作，结束后准确复位。
- 连续点击后木锤不漂移、不跳回旧的 `-12` 度角度。
- ArkTS 静态检查、Hypium 测试及 debug、release 构建通过。
- 在可用设备上安装 debug HAP，启动 `com.max.muyu/EntryAbility`，检查静止画面并实际触发击打动画。
