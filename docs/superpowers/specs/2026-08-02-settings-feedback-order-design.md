# 设置反馈项分组排序设计

## 目标

调整设置页“敲击反馈”卡片内现有项目的顺序，使带开关的项目连续排列、带箭头的入口连续排列，并通过音量控件自然衔接两组。

## 最终顺序

1. 音效开关
2. 振动反馈
3. 浮动文字
4. 音量
5. 音色选择
6. 自定义文字

## 视觉规则

- 三个开关项目连续排列，保持右侧开关纵向对齐。
- 音量保留现有行高、滑块和上下分隔线，作为开关组与箭头组之间的中性过渡。
- 音色选择和自定义文字连续排列，保持右侧箭头纵向对齐。
- 不增加分组标题、色块、额外留白或嵌套卡片。
- 不修改颜色、字号、间距、圆角、图标、文案和触控目标。

## 行为边界

- 不改变音效、振动、浮动文字、音量、音色和自定义文字的回调及持久化逻辑。
- 不改变深浅色主题表现。
- 不改变卡片之外的外观、数据、隐私和底部导航区域。
- 不修改应用标识、版本、签名或权限。

## 验收

- 静态检查锁定六项最终顺序，并确认每项只出现一次。
- Hypium、debug、ohosTest 和 release 构建通过。
- phone 设置页截图确认开关组、音量过渡和箭头组排列协调。
- tablet、2in1 无可用设备时继续标记为 `blocked`。
